# Homepage Content & Structure Rewrite — Spec

> Note: no issue-tracker/triage-label vocabulary was configured in this workspace (no `/setup-matt-pocock-skills` output found, no tracker MCP tool available), so this spec is saved locally instead of being published to a tracker. No automated test framework exists in this repo either — see Testing Decisions.

## Problem Statement

The current homepage copy (Hero, About, Services) is generic and doesn't reflect how Romana actually wants to position her coaching business. It leads with credentials and a service-list structure instead of speaking to the visitor's actual situation (stuck in a cycle of starting/stopping, unsure what to believe, no time), building a narrative case for *why* strength training matters, and then walking the visitor through a clear path (get to know each other → find direction → build a system) before presenting the three ways to work together. Testimonials, a shared-movement/community section, and an FAQ are also missing entirely.

## Solution

Replace the homepage body with a new 14-part narrative flow (numbered per the source content), each part a self-contained section component, composed in order in `App.tsx`. Content flows: Hero → Manifesto → "stuck in a cycle" pain section → foundations of lasting change → why build strength at all → what the coaching journey looks like → how she can help → the three ways to work together → why she does this work → (testimonials, reserved for later) → community/shared movement → FAQ → closing banner → contact form. Header nav is trimmed to 4 links pointing at the sections that best represent them. Visual design keeps the existing design language (cream/white backgrounds, orange accent, `flat-card`, `btn-pill`, Oswald/Inter type) for most sections, and introduces two new, deliberately-scoped patterns: an **editorial text-block** style (used on the two most narrative/emotional sections, with a dark-background variant) and a **closing-statement** style (a short emphasized line used to cap a couple of sections).

## User Stories

1. As a first-time visitor, I want to immediately understand who Romana is and what outcome she promises, so that I know within seconds whether this site is relevant to me.
2. As a first-time visitor, I want a clear primary action ("Rezervovat úvodní konzultaci") visible in the hero, so that I can act immediately if I'm ready.
3. As a visitor who isn't ready to commit yet, I want a secondary "Zjistit více" action that scrolls me into the content instead of straight to a form, so that I can learn more before deciding.
4. As a visitor, I want the hero photo to stay exactly as it is today, so that the one existing visual asset isn't wasted or degraded.
5. As a visitor, I want a short, unadorned statement of Romana's core beliefs (the Manifesto) with no distracting heading or imagery, so that it reads like a calm, confident personal statement rather than marketing copy.
6. As a visitor who has tried and failed to build lasting fitness habits before, I want to see my exact situation described back to me (starting and stopping, trying different approaches, not knowing what to believe, no energy/time), so that I feel understood before being sold anything.
7. As a visitor reading the "stuck in a cycle" section, I want each thought presented with its own visual space rather than as a bulleted list, so that it feels like someone talking to me, not a checklist.
8. As a visitor, I want to understand the philosophy that lasting change comes from foundations, not motivation, so that I trust the approach is different from "30-day transformation" marketing.
9. As a visitor, I want to see the four foundations (Pohyb, Výživa, Regenerace, Návyky) laid out clearly with a short explanation each, so that I understand the scope of what "coaching" actually covers.
10. As a visitor, I want a short, emphasized closing line after the foundations section, so that the takeaway ("build a system, not reliance on motivation") is unmistakable.
11. As a visitor, I want a section that makes the emotional case for *why* building strength matters (energy, independence, confidence, longevity), so that I connect strength training to my actual life goals, not just aesthetics.
12. As a visitor, I want that section's six "Because…" statements to read as a flowing, vertical progression rather than a grid of equal boxes, so that it builds like an argument, ending in a personal, attributed quote from Romana.
13. As a visitor, I want to see Romana's personal attributed quote ("Pro mě síla už dávno není o tom být nejlepší…") set apart with generous space, so that it lands as the emotional high point of the section.
14. As a prospective client, I want to see the 5-step journey (Poznáme se → Najdeme směr → Začneme stavět → Učíme se za pochodu → Vytváříš si vlastní systém) laid out as a clear horizontal sequence, so that I know what working together actually looks like over time.
15. As a prospective client, I want a closing line clarifying that the goal is for me to become independent, not permanently reliant on the coach, so that I trust the relationship is designed to end well for me.
16. As a visitor, I want a clear, scannable list of the specific problems Romana can help with (gym beginners, strength building, sustainable weight loss, habits/nutrition relationship, energy, life transitions), so that I can quickly self-identify with one or more.
17. As a prospective client, I want to see the three ways of working together (Hybrid, Online, Personal/in-person) presented side by side with a description and "ideal for" line each, so that I can pick the one that fits my situation.
18. As a prospective client, I want the Hybrid option visually marked as the most popular choice, so that I have a sensible default if I'm unsure.
19. As a visitor, I want to read Romana's personal "why I do this" story (family, longevity, freedom in her own body), so that I trust her motivation is genuine and not purely commercial.
20. As a visitor, I want the personal essay to end on its own poetic, short-line closing (about freedom, courage, resilience) without it being squeezed into a generic boxed "closing statement" style, so that its tone stays distinct and personal.
21. As a returning or skeptical visitor, I want to eventually see testimonials from other clients, so that I can validate the coaching works for people like me — though this section is explicitly deferred and not part of this build.
22. As a visitor, I want to see that movement can be shared/social (Run club, Community, Instagram), so that I understand support isn't limited to 1:1 sessions — even without needing to click through anywhere yet.
23. As a hesitant visitor, I want an FAQ that addresses my most common doubts (never trained before, uncomfortable in a gym, dieting/counting calories, limited time, what the first consultation looks like, how to choose a coaching form), so that common objections are pre-answered.
24. As a visitor browsing the FAQ, I want to click a question to expand only its answer (accordion, one open at a time), so that the list stays scannable and I'm not overwhelmed by a wall of text.
25. As a visitor who has read the FAQ, I want a final reassuring line ("Každá z nás někdy začínala…") and a CTA to book a consultation, so that I'm nudged to act right after my doubts are addressed.
26. As a visitor nearing the bottom of the page, I want a bold, visually distinct closing banner reaffirming that every woman deserves to feel strong, so that the page builds to a confident close before the contact form.
27. As a visitor ready to reach out, I want the existing contact form (name/email/message + reCAPTCHA + email send) to keep working exactly as it does today, so that this rewrite doesn't regress lead capture.
28. As a returning visitor using the nav, I want "Tvoje cesta" to jump to the journey section, "Formy spolupráce" to jump to the three coaching-form cards, "O mně" to jump to the personal "why I do this" story, and "Kontakt" to jump to the form, so that the nav reflects the new content structure instead of the old Home/About/Services/Contact model.
29. As a visitor, I want the "Domů"/Home nav link removed since scrolling to the top is already possible via the logo/hero, so that the nav only surfaces meaningful destinations.
30. As an English-speaking visitor, I want the language switcher to keep working, so that I'm not blocked from using the site — even though the English copy will initially just mirror the Czech 1:1 until real translations are written (tracked as follow-up, not part of this build).
31. As a visitor using a screen reader or keyboard, I want the new dark-background editorial sections to keep sufficient text/background contrast and semantic heading structure, so that the visual redesign doesn't regress accessibility.
32. As a mobile visitor, I want every new section (editorial blocks, horizontal timeline, card grids, accordion, closing banner) to reflow sensibly on small screens, so that the experience isn't degraded on the majority device type.
33. As a visitor with `prefers-reduced-motion` enabled, I want the existing scroll-reveal (`animate-on-scroll`) behavior to continue to apply consistently to the new sections, so that motion preferences are still respected.
34. As the site owner, I want all old About/Services copy (mission, why-choose-me, how-I-work, qualifications, hybrid/online service descriptions) removed from the codebase once superseded, so that there's no dead/duplicate content confusing future edits.
35. As the site owner, I want the qualifications/certifications content (NASM, Fitness Institut, Yoga TT) dropped entirely since it isn't part of the new narrative, so that the page copy matches the new notes exactly.
36. As a future maintainer, I want each of the 14 sections to be its own named component (not a monolithic file), so that individual sections can be edited, reordered, or removed independently.
37. As a future maintainer, I want section 10 (testimonials) to leave a numbering gap (9 → 11) with no stub file, so that its eventual addition is an obvious, deliberate insertion rather than a rename/renumber exercise.

## Implementation Decisions

- **Modules built** (new components under `src/components/`): `Manifesto`, `StuckInCircle`, `Foundations`, `WhyStrength`, `YourJourney`, `HowICanHelp`, `ChooseYourPath`, `WhyIDoThis`, `MovementShared`, `FAQ`, `ClosingBanner`. Section numbering: 1 Hero, 2 Manifesto, 3 StuckInCircle, 4 Foundations, 5 WhyStrength, 6 YourJourney, 7 HowICanHelp, 8 ChooseYourPath, 9 WhyIDoThis, **10 reserved/skipped**, 11 MovementShared, 12 FAQ, 13 ClosingBanner, 14 Contact.
- **Modules modified**: `Hero.tsx` (copy + CTA targets only, photo/markup otherwise unchanged), `Contact.tsx` (no functional change), `Header.tsx` (nav links/anchors), `App.tsx` (new composition order), `translations.ts` (old `about`/`services` keys removed, replaced by one key namespace per new section), `index.css` (two new shared style patterns).
- **`About.tsx` and `Services.tsx` are deleted**, fully superseded by the new section components; no qualifications/certifications content is carried forward.
- **Header nav** becomes exactly 4 items in this order: Tvoje cesta (→ `YourJourney`, section 6), Formy spolupráce (→ `ChooseYourPath`, section 8), O mně (→ `WhyIDoThis`, section 9), Kontakt (→ `Contact`, section 14). "Domů" is removed. New semantic anchor ids are introduced for these targets (exact id strings are an implementation detail decided at build time, not fixed by this spec).
- **Hero**: removes the "Romana Vítková / Women's Fitness Coach" heading entirely; photo, background, and layout scaffolding unchanged. New headline: "Pomáhám ženám vybudovat sílu, která vydrží celý život." New supporting paragraph: "Síla není jen o tom, kolik zvedneš na čince…". Primary CTA "Rezervovat úvodní konzultaci" → `#contact`. Secondary CTA "Zjistit více" → scrolls directly to section 3 (`StuckInCircle`), intentionally skipping past the Manifesto.
- **Manifesto (2)**: plain white background, no heading, no image, no card/border — just the three belief sentences, large centered type, generous vertical padding.
- **Editorial text-block pattern** (new, shared CSS/utility approach, not a full component library): eyebrow label (small uppercase, orange, tracking-wide) + large `font-display` heading that mixes upright bold text with an italicized emphasis phrase, generous line-height and spacing between subsequent thought blocks, no card/border. Used with a **dark background** (deliberate contrast/break from the site's light theme) on sections `StuckInCircle` (3) and `WhyStrength` (5). Used on a **light/cream background** for `WhyIDoThis` (9) — same typographic idea, no dark treatment there.
- **`StuckInCircle` (3)**: dark editorial section. Big multi-line heading, then the 5 "thought" statements each given their own spacing (not a bulleted list), followed by the two closing paragraphs ("Možná už jsi to zkoušela změnit…" / "Nechci ti dát další univerzální návod…").
- **`Foundations` (4)**: intro paragraph, then a 2×2 `flat-card` grid (reusing the existing card language) — one card per pillar (Pohyb, Výživa, Regenerace, Návyky), each with a number badge + icon + short text. Ends in the shared **closing-statement** style (see below).
- **Closing-statement pattern** (new, shared): centered, slightly-larger italic text, orange accent, no attribution. Used at the end of `Foundations` (4) and `YourJourney` (6) only — not used on `WhyStrength` (5, which has its own attributed Quote variant) nor `WhyIDoThis` (9, whose ending stays inline as part of the essay's own flow).
- **`WhyStrength` (5)**: dark editorial section per the pattern above; the six "Protože…" statements are stacked vertically as a building progression (not a grid); ends, after a large deliberate gap, in a distinct **Quote** treatment: large italic text, orange accent mark or left border, centered, attributed "— Romana Vítková" beneath in small caps/letter-spacing.
- **`YourJourney` (6)**: horizontal timeline for the 5 steps — numbered nodes connected by a line, laid out along one horizontal axis on wider viewports (stacking vertically on narrow viewports), each with a short label + description. Ends in the shared closing-statement style.
- **`HowICanHelp` (7)**: 3×2 icon `flat-card` grid (matching `Services`/`About`'s existing card language) for the six help topics (gym beginners, strength building, sustainable weight loss, movement/nutrition relationship, energy, life transitions).
- **`ChooseYourPath` (8)**: intro paragraph, then a 3-column `flat-card` grid — Hybrid coaching, Online coaching, Personal coaching (see `CONTEXT.md` — three distinct offerings, not two). Hybrid gets a "Nejoblíbenější" badge plus an orange border/highlight treatment; the other two cards are visually plain.
- **`WhyIDoThis` (9)**: editorial text-block style on a light background; personal essay content (longevity, family, freedom in the body); ends with the short poetic lines inline as the section's natural close (no separate boxed "closing statement").
- **Section 10 (testimonials)**: intentionally not built. No component, no route, no placeholder. The number is reserved so `MovementShared` remains "11" in code/comments, making the future insertion point obvious.
- **`MovementShared` (11)**: 3-card info grid (Run club, Community, Instagram) — informational only, no links/hrefs, since no destinations exist yet.
- **`FAQ` (12)**: new accordion component (first of its kind in this codebase) — single-open-at-a-time expand/collapse over the 6 Q&A pairs from the notes, used verbatim including the two pairs that share duplicated answer text in the source notes. Ends with the "Každá z nás někdy začínala…" line and a "Rezervovat úvodní konzultaci" CTA → `#contact`.
- **`ClosingBanner` (13)**: full-width bold color band (distinct visual break, consistent with the new dark/bold sections introduced elsewhere), centered heading "Každá žena si zaslouží cítit se silná." with a smaller secondary line ("Ať už začínáš úplně od nuly…") beneath, positioned directly above `Contact`.
- **`Contact` (14)**: unchanged functionally (form fields, reCAPTCHA, `/api/send-email` submission, success/error handling); only surrounding copy/heading may be revisited for tone consistency, not its mechanics.
- **`translations.ts`**: `about` and `services` key namespaces are deleted; one new key namespace per new section is added (e.g. `manifesto`, `stuckInCircle`, `foundations`, `whyStrength`, `yourJourney`, `howICanHelp`, `chooseYourPath`, `whyIDoThis`, `movementShared`, `faq`, `closingBanner`). Both `cs` and `en` are populated for every new key; `en` initially duplicates the `cs` text verbatim as a placeholder (tracked as a follow-up to get real English copy — flag this explicitly when this spec is turned into an implementation plan).
- **Images**: no new image assets. `hero.jpg` remains the only image on the page, used only in `Hero`. All other sections are text/UX only.
- **Domain glossary**: `CONTEXT.md` already updated with the Hybrid/Online/Personal coaching distinction; no other domain terms surfaced during this rewrite.

## Testing Decisions

- **No automated test framework exists in this repository** (no Jest/Vitest/Playwright config, no test scripts in `package.json`). This spec does not introduce one — adding a test framework would be a separate, explicitly-scoped decision, not a side effect of a content rewrite.
- **Highest available seam**: each new/changed file is its own component (`Hero`, `Manifesto`, `StuckInCircle`, … `Contact`), composed once in `App.tsx`. This is the natural verification boundary — one component, one section, one visual review pass — and is preferred over introducing any new cross-cutting abstraction.
- **Verification for this change is**: (1) `npm run typecheck` and `npm run lint` pass with no new errors; (2) `npm run build` succeeds; (3) manual visual QA of each section at mobile and desktop widths, including the new dark editorial sections (contrast check), the horizontal timeline (mobile reflow), the FAQ accordion (expand/collapse, only one open at a time), and the language switcher (cs/en both render without missing-key errors); (4) confirm nav anchors scroll to the correct new sections; (5) confirm the contact form still submits successfully end-to-end (existing behavior, not touched).
- **Prior art**: none of the existing components have automated tests to follow as precedent; the `animate-on-scroll`/`IntersectionObserver` wiring in `App.tsx` is the one piece of existing "cross-section" behavior new sections must remain compatible with (each new section's revealed elements need the `animate-on-scroll` class + `data-delay` attribute, matching the existing convention in `About.tsx`/`Services.tsx`).

## Out of Scope

- Section 10 (testimonials) — explicitly deferred, not built, not stubbed.
- Real English translations — `en` will mirror `cs` as a placeholder; producing accurate English copy is a follow-up task.
- New photography/image assets for any section beyond the existing hero photo.
- Live links/destinations for Run club, Community, or Instagram in `MovementShared` (11) — informational only for now.
- Any change to the contact form's mechanics, `api/send-email.ts`, or reCAPTCHA integration.
- Introducing an automated test framework.
- Renaming/restructuring the qualifications/certifications content — it is deleted, not migrated.
- Exact final anchor-id strings and Tailwind class-level styling details — left to implementation, constrained only by the patterns described above (editorial block, closing-statement, Quote, horizontal timeline, accordion, color-band banner).
